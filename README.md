# LogicSimulatorPython

Description:

Event-Driven Combinational/Sequential Logic Simulator in Python

Files:

    logic_simulator.py               : Python code

    c17.lev                          : Input circuit file (for e.g. c17) in lev format

    c17.vec                          : Input vector file (for e.g. c17)

Execution:

    python logic_simulator.py c17
